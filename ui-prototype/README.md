# BrainRoom UI 초안

시작 화면부터 팀 공간, 공유 보드, 팀원별 공간까지 살펴볼 수 있는 독립적인 프론트엔드 초안입니다. 기존 저장소의 앱을 교체하거나 Firebase 백엔드와 연결한 버전은 아닙니다.

## 실행하기

Node.js 22.13 이상이 필요합니다. 저장소를 내려받은 뒤 이 폴더에서 아래 명령을 실행하세요.

```bash
cd ui-prototype
npm install
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 `http://localhost:3000`)를 열면 시작 화면이 나옵니다. 시작하기를 누르면 팀 공간으로 이동하고, 가운데 공유 보드에서 일정과 자료를 추가해 볼 수 있습니다.

## 초안의 범위

- ‘캠퍼스 우산 대여’는 가상의 예시 프로젝트입니다.
- 추가한 일정과 자료는 **해당 브라우저에만 저장**되며 다른 팀원과 공유되지 않습니다.
- 로그인, Firebase, Figma, GitHub, AI 기능은 이 초안에 연결되어 있지 않습니다. Figma와 GitHub 화면에 표시된 내용은 예시입니다.
- 이 폴더는 기존 HTML/JavaScript 앱과 별도로 실행하는 Next.js 기반 UI 초안입니다. 실제 앱에 적용할 때는 화면과 데이터 연결을 별도로 작업해야 합니다.
