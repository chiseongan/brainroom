BrainRoom 대화 담기 (Chrome 확장) {version} — 설치 방법
=====================================================

ChatGPT·Claude·Gemini에서 고른 대화를 BrainRoom 방으로 보내는 확장입니다.
(켜 둔 동안만 구글·네이버 검색 기록을 모아 고른 것만 보내는 '탐색 기록'도 있습니다)
서버로 보내지 않고, 내 브라우저에 열려 있는 BrainRoom 탭으로만 전달합니다.

[설치] Chrome · Edge · 네이버 웨일 (PC에서만)
1. 이 zip 파일의 압축을 풉니다.
2. 브라우저 주소창에 아래 주소를 엽니다.
     Chrome: chrome://extensions
     Edge:   edge://extensions
     웨일:    whale://extensions
3. '개발자 모드'를 켭니다. (Chrome은 오른쪽 위, Edge는 왼쪽 메뉴 아래)
4. '압축해제된 확장 프로그램을 로드합니다'(Edge: '압축을 푼 항목 로드')를 누르고,
   압축을 푼 폴더 안의 'brainroom-extension' 폴더를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘에서 'BrainRoom 대화 담기'를 고정(📌)해 두면 편합니다.

[쓰는 법]
1. BrainRoom(https://chiseongan.github.io/brainroom/)에 로그인하고 내 방에 들어가 둡니다.
2. ChatGPT·Claude·Gemini 대화 화면 오른쪽 아래 '🧠 BrainRoom에 담기'를 누릅니다.
   - 글을 드래그해 선택한 상태로 누르면 그 부분만 보냅니다.
   - 버튼이 안 보이면 페이지를 새로고침하세요.
3. BrainRoom 탭에 'AI 대화 불러오기' 창이 뜨면, 담을 대화를 고르고 공유 범위(나만/팀/교수자까지)를 정해 저장합니다.

[검색 기록 담기 (선택)]
- 확장 아이콘을 눌러 '🔍 탐색 기록 켜기'를 켠 동안만, 구글·네이버의 검색어와 누른 결과가 이 브라우저에 모입니다.
- 켜져 있으면 검색 화면 오른쪽 아래에 '탐색 기록 중' 표시가 뜹니다.
- 확장 창에서 보낼 검색을 골라 '고른 검색 보내기'를 누르면 BrainRoom으로 갑니다. 기본 공유 범위는 '나만'입니다.

[알아둘 점]
- 업데이트는 자동으로 되지 않습니다. 새 zip을 받으면 같은 폴더에 덮어쓰고 확장 화면에서 새로고침(↻)을 누르세요.
- 믿을 수 있는 사람에게 받은 zip만 설치하세요. 확장은 AI 대화 화면을 읽을 수 있습니다.
- 브라우저가 가끔 '개발자 모드 확장 프로그램' 경고를 띄우지만 계속 쓸 수 있습니다.
- 휴대폰 브라우저에서는 쓸 수 없습니다.
- 사이트가 화면을 바꾸면 대화를 못 읽을 수 있습니다. 그때는 글을 선택해서 보내거나 BrainRoom의 'AI 대화 파일 불러오기'를 쓰세요.
