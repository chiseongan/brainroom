# 🧠 BrainRoom (MVP)

팀원 각자가 찾아본 자료가 **방 인테리어**로 변하는 팀 브레인스토밍 가상 오피스.

## 실행
- 빌드 과정이 없습니다. `index.html`을 더블클릭하면 바로 실행돼요.
- 로컬 서버로 띄우려면: `python -m http.server 5173` → http://localhost:5173
- 시작 화면에서 **"샘플 팀으로 체험하기"** 를 누르면 데모 데이터가 채워집니다.
- `js/firebase-config.js`가 비어 있으면 로그인 없는 **데모 모드**로 동작합니다.

## Google 로그인 설정 (Firebase)
1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → Google** 사용 설정 (프로젝트 지원 이메일 선택 후 저장)
3. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(</>)** 앱 등록 → 표시되는 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 `js/firebase-config.js`에 붙여넣기
4. **Authentication → 설정 → 승인된 도메인**: `localhost`는 기본 포함. 배포하면 배포 주소를 추가
5. 반드시 로컬 서버로 실행: `python -m http.server 5173` → http://localhost:5173 (파일 더블클릭으로는 로그인이 안 됨)

로그인 후 흐름: 처음 로그인하면 "누구의 방을 쓰시나요?" 화면에서 기존 팀원을 고르거나 새 팀원으로 참여합니다. 이후에는 그 계정이 해당 팀원으로 고정됩니다.

## 온라인 팀 설정 (Firestore)
Google 로그인 설정을 마친 뒤 이어서 하면, 팀원끼리 실시간으로 공유되고 공유 범위·교수자 권한이 서버 규칙으로 강제됩니다.
1. Firebase 콘솔 → **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, **프로덕션 모드**)
2. **규칙** 탭에 저장소의 [`firestore.rules`](firestore.rules) 내용을 그대로 붙여넣고 **게시**
3. 앱에서 로그인 → **🌐 온라인 팀 만들기**
4. ⚙️ 메뉴 → **초대 링크** 복사
   - 팀원 초대 링크: 팀원에게 전달 → 로그인 후 자기 이름을 고르면 참여
   - 교수자 초대 링크 (팀장만 보임): 교수자에게 전달 → 교수자 보기로만 열림
5. 무료 Spark 요금제 한도(하루 읽기 5만·쓰기 2만 회) 안에서 수업용으로 충분합니다.

| 저장 위치 | 내용 | 누가 읽나 |
|---|---|---|
| `teams/{팀}` | 팀 이름, 수업명, 팀원 명단 | 팀원, 교수자 |
| `…/items` | 기록 내용 | 나만=본인 / 팀=팀원 / 교수자까지=팀원+교수자 |
| `…/itemMeta` | 기록 종류·시각·AI 목적 (내용 없음) | 팀원, 교수자 (횟수 집계용) |
| `…/secrets` | 초대 코드 | 팀원 코드=팀원, 교수자 코드=팀장 |
| `…/accessLogs` | 권한 없는 접근 시도 | 팀장 |

- `firebase-config.js`가 비어 있으면 예전처럼 이 브라우저에만 저장하는 데모 모드로 동작합니다.
- 로그인 화면의 **🎲 로그인 없이 샘플 팀으로 체험하기**는 아무 데도 저장하지 않습니다.
- 로그인 후 시작 화면에서 **샘플 팀 / 이 브라우저에 있던 팀 / 워크스페이스 파일**을 새 온라인 팀으로 올릴 수 있습니다. 내가 아닌 팀원 이름으로 된 기록은 **📥 가져온 기록**으로 표시되고 올린 사람이 관리합니다.
- ⚙️ 메뉴 → **🚪 이 팀에서 나가기**: 내 계정만 빠지고 팀 데이터는 남습니다. 초대 링크로 다시 들어올 수 있습니다.

## Chrome 확장: AI 대화 담기 (`extension/`)
ChatGPT·Claude·Gemini 화면 오른쪽 아래 **🧠 BrainRoom에 담기** 버튼(또는 오른쪽 클릭 메뉴)으로 지금 보고 있는 대화를 BrainRoom으로 보냅니다. 글을 드래그해 선택한 상태면 그 부분만 보냅니다.
- 서버로 보내지 않고 **열려 있는 BrainRoom 탭으로만** 전달합니다. 탭이 없으면 새로 엽니다.
- BrainRoom에서는 **AI 대화 불러오기 창**이 떠서 고른 대화만 저장합니다(개인정보 가리기·공유 범위 그대로). 원래 대화 주소가 근거 링크로 남습니다.
- 각 사이트의 화면 구조를 읽는 방식이라 사이트가 화면을 바꾸면 못 읽을 수 있습니다. 그때는 글을 선택해서 보내거나 내보내기 파일을 쓰세요.

설치 (Chrome·Edge·웨일)
1. 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
3. 확장 아이콘 → **보낼 BrainRoom**을 배포 주소 또는 `localhost:5173`으로 고르기

## 기능
| 화면 | 기능 |
|---|---|
| 회의실 (메인) | 벽의 팀원별 문 → 클릭하면 그 팀원의 방으로 이동 |
| 전체 보기 | 팀원별 방 미리보기, 겹치는 관심사 |
| 내 방 | 자료·메모·아이디어 담기 → 키워드/주제 자동 추출 → 방 꾸며짐 |
| 방 오브젝트 | 📚 책장=자료, 🗒️ 포스트잇=메모, 💡 화이트보드=아이디어, 테마 소품=주제, 조명=최근 활동 |
| 회의실 | 드래그로 테이블에 올리기, 공통점 연결선, 추천 연결, 👍 투표 |
| 초안 문서 | 회의 결과와 확정된 결정을 Markdown으로 복사/다운로드 |
| 🕒 타임라인 | 보이는 기록과 확정된 결정을 시간순으로, 팀원·종류별 필터 |
| ✅ 결정 | 메모·아이디어·AI 대화에서 "하기로 했다/결정/확정" 문장을 후보로 추출 → 확정·수정·무시. 근거 없는 결정은 "확인 필요"로 분리 |
| 📊 리포트 | 팀원별 기록 종류·결정 근거 수·AI 활용 목적 (점수 없음). 기록 없는 팀원은 안내 문구 표시. 기여 보정 요청 → 다른 팀원 확인 시 반영, 변경 이력 |
| 🎯 퀘스트 | 전체 보기 상단. 주차별 목표 → 담긴 기록·확정된 결정으로 진행률 자동 계산 |
| 🖥️ AI 대화 | 대화 붙여넣기 또는 ChatGPT·Claude 내보내기 `conversations.json`/.txt 불러오기 → 고른 대화만 저장, 사용 목적(조사·초안·코드·번역·아이디어) 자동 분류 |
| 🔒 공유 범위 | 기록마다 나만 / 팀 / 교수자까지 (기본 "나만"). 회의 테이블에 올리면 팀 공개로 바뀜 |
| 🎓 교수자 보기 | "나" 선택 → 🎓 교수자 (또는 ⚙️ 메뉴). 팀별 이번 주 기록 수·결정 수·참여 편중, '교수자까지' 기록만 원문 열람. 팀 제출 파일을 여러 개 불러와 수업별로 비교 |
| 🎙️ 회의 | 온라인 방 팀원끼리 음성·화상 회의 (브라우저 직접 연결, 4명 안팎 권장). 각자 자기 마이크를 받아써 발언자별 녹취록을 남기고, 회의가 끝나면 참석자·발언 수·키워드·주요 발언·정한 것으로 요약. 회의 중에도 다른 화면 이용 가능 (Chrome·Edge) |
| 🎙️ 회의 발언 | 회의가 끝나면 각자 **내가 한 말**을 요약·키워드로 저장해 내 방에 담음. 방에 🎙️ 마이크 스탠드가 생기고, 키워드는 어울리는 **사물**로 놓임 (재활용 → 분리수거함, 교육 → 책상 위 교과서, 일정 → 벽 달력, 발표 → 연단 등 34종). 누르면 그 회의 요약을 봄. 키워드→사물 사전과 그림은 `js/decor.js` |
| 🔌 연동 | **GitHub**(내 커밋·PR, AI 공동 작성 🤖 표시) · **Figma**(내 버전·댓글, 하루 단위) · **Notion**(내가 마지막으로 고친 페이지·DB 항목, 내 댓글). 각자 본인 토큰으로 연결하고 본인 작업만 가져옴. 토큰은 그 브라우저에만 저장. 방 공용으로 저장소·파일·페이지를 지정, 15분마다 자동으로 가져옴. 방에는 노트북·그림 이젤·서류 더미로 나타남. 연동 안 한 팀원은 리포트에 '연동 안 됨' |

### 팀트레이스 SSRD 반영 범위
- 저장 전에 이메일·전화번호·주민등록번호 형태 문자열을 가리고, AI 대화 원문은 대화당 6,000자까지만 보관 (LS-4)
- 같은 링크·제목·대화를 다시 담으면 중복으로 막음 (ONRQ-4)
- 교수자 보기에서 학생 화면으로 이동하려 하면 막고 기록을 남김 (ONRQ-5, UI-4)
- 방 명패의 Lv 표시를 없애고 "오늘 활동 / n일 전 활동" 글자로 상태 표시 (LS-8, UI-3)
- 보조 글자 색 대비 4.5:1 이상, 폭 400px에서 가로 스크롤 없음 (UI-1, UI-3)
- ⚙️ 메뉴의 내보내기 3종: 팀 공유용(나만 기록 제외) / 교수자 제출용('교수자까지'만 내용 포함) / 전체 백업

```
js/firebase-config.js  Firebase 웹 앱 설정값 (직접 입력)
js/auth.js     Google 로그인 (Firebase Authentication)

js/trace.js    공유 범위, 개인정보 가리기, AI 대화 파싱·분류, 결정 추출, 퀘스트, 보정 요청, 교수자 집계
js/views.js    타임라인, 결정, 리포트, 퀘스트, AI 대화 불러오기, 교수자 보기 화면
js/meeting.js  음성·화상 회의 (WebRTC + Firestore 신호), 받아쓰기, 회의 요약
js/decor.js    회의 키워드 → 방 사물 (책상 위·바닥·벽에 2.5D로 그림)
js/integrations.js  GitHub·Figma·Notion 연동 (브라우저에서 공식 API 호출, 본인 토큰)
js/extension.js  Chrome 확장이 보낸 AI 대화 받기 → 불러오기 창
extension/     Chrome 확장 (capture.js: AI 사이트, bridge.js: BrainRoom 페이지, background.js: 전달)
js/cloud.js    온라인 팀 (Firestore 실시간 공유, 초대 링크, 교수자 권한)
firestore.rules  Firestore 보안 규칙 (공유 범위·역할 강제)
js/iso.js      2.5D 아이소메트릭 SVG 엔진 (박스·벽·바닥·캐릭터·식물)
js/room.js     개인 방 씬
js/hall.js     회의실 씬 (팀원 방 문, 테이블, 캐릭터)
js/app.js      화면, 이벤트, 회의실, 내보내기
```

## MVP의 한계와 다음 단계
- 데모 모드에서는 데이터가 **브라우저(localStorage)에만** 저장되고, 팀원과는 파일로 주고받습니다. 온라인 팀(Firestore)을 쓰면 실시간으로 공유됩니다.
- 상단의 "나" 선택은 데모 모드에서만 보이는, 한 기기에서 여러 팀원을 시연하기 위한 전환입니다.
- 키워드 추출은 규칙 기반입니다. → 다음 단계: LLM 요약/분류, 임베딩 유사도로 연결 추천
- 가구·캐릭터는 SVG 도형으로 그립니다. 픽셀 아트 스프라이트(예: CC0 에셋)로 교체하려면 js/iso.js의 그리기 함수만 바꾸면 됩니다.
- 데모 모드의 공유 범위와 교수자 보기는 화면에서만 거르는 시연용입니다. 온라인 팀에서는 `firestore.rules`가 서버에서 강제합니다.
- 온라인 팀에서 같은 기록을 두 사람이 동시에 고치면 나중에 저장한 쪽이 남습니다 (투표는 합쳐짐).
- Notion·Figma·Google Meet 자동 연동과 Chrome 확장은 서버(또는 서버리스 프록시)가 필요해 포함하지 않았습니다. 지금은 링크·내용 붙여넣기와 AI 대화 파일 불러오기로 대신합니다.
