# BrainRoom 사용 안내

독자: BrainRoom을 처음 쓰는 팀원과 교수자. 주소는 https://chiseongan.github.io/brainroom/ 입니다. PC의 Chrome이나 Edge를 권장합니다.

## 시작하기

1. Google 계정으로 로그인합니다.
2. **방 만들기** 또는 **방 참여하기**를 고릅니다. 팀원에게 받은 초대 링크를 열면 바로 참여합니다.
3. "누구의 방을 쓰시나요?"에서 자기 이름을 고릅니다. 없으면 새 팀원으로 참여합니다. 한 번 고른 이름은 그 계정 전용이 됩니다.

팀원을 부르려면 상단 **🔗 초대 링크**를 복사해 보내세요.

## 기록 남기기

| 기록 | 담는 방법 | 방에 나타나는 곳 |
|---|---|---|
| 📚 자료·링크, 🗒️ 메모, 💡 아이디어 | 내 방에서 직접 입력 | 책장, 포스트잇, 화이트보드 |
| 🖥️ AI 대화 | 확장 프로그램 버튼, 또는 내보낸 대화 파일 올리기 | 모니터 |
| 🔍 검색 | 확장 프로그램의 탐색 기록을 켠 동안 모은 것 중 고른 것 | 돋보기 |
| 🎙️ 회의 발언 | 회의가 끝나면 내가 한 말이 자동으로 요약됨 | 마이크 |
| 🛠️ 작업 | 🔌 연동에서 GitHub·Figma·Notion 연결 | 노트북, 이젤, 서류 더미 |

기록의 키워드는 방 안의 물품이 됩니다. 재활용 이야기를 하면 분리수거함이, 일정 이야기를 하면 달력이 생기는 식입니다. "정리·수정·팀"처럼 어디에나 나오는 말은 그 기록에 더 구체적인 말이 없을 때만 물품이 됩니다. 물품은 책상과 바닥, 벽에 자리가 있는 만큼 많이 나온 순서로 놓이고, 전체 목록은 방 옆 **방의 물품** 칸에서 볼 수 있습니다.

## 공유 범위

기록마다 고를 수 있고, 기본값은 **🔒 나만**입니다.

| 범위 | 내용을 보는 사람 |
|---|---|
| 🔒 나만 | 나 |
| 👥 팀 | 방의 팀원 |
| 🎓 교수자까지 | 방의 팀원과 교수자 |

"나만" 기록도 **있다는 사실과 횟수**는 팀원과 교수자의 집계에 들어갑니다. 내용은 보이지 않습니다. 저장 전에 이메일, 전화번호, 주민등록번호 형태는 자동으로 가립니다.

## 회의

1. **🎙️ 회의**에서 회의를 시작하면 팀원이 참여할 수 있습니다. 4명 안팎을 권장합니다.
2. 받아쓰기를 켜면 각자 자기 마이크만 글자로 바뀌어, 누가 말했는지 구분됩니다. 이어폰을 쓰면 다른 사람 목소리가 섞이지 않습니다.
3. 회의가 끝나면 요약이 남고, 각자 방에 "내가 한 말"이 담깁니다. 정한 것으로 보이는 말은 **✅ 결정** 후보로 올라옵니다.

- Google Meet으로 회의했다면 녹취록을 가져와 같은 방식으로 정리할 수 있습니다.
- 회의를 시작한 사람과 팀장은 회의 기록과 녹취를 지울 수 있습니다. "내가 한 말" 기록은 각자 지웁니다.
- 지난 회의마다 **교수자에게 요약 공유**를 켤 수 있습니다. 녹취 원문은 공유되지 않습니다.

## 팀 작업

- **🗂️ 회의실**: 아이디어를 테이블로 끌어 올리고 투표합니다. 테이블에 올린 기록은 팀 공개로 바뀝니다.
- **✅ 결정**: 후보를 확정, 수정, 무시합니다. 근거 기록이 없는 결정은 "확인 필요"로 따로 모입니다.
- **📊 리포트**: 팀원별 기록과 근거를 보여 줍니다. 점수는 없고, 기록이 없다고 기여가 없다는 뜻은 아닙니다. 빠진 기여는 보정 요청을 보내면 다른 팀원이 확인해 반영합니다.
- **🎯 퀘스트**: 주차별 목표의 진행률을 자동으로 계산합니다.
- **🗓️ 주간 요약**: 📊 리포트 맨 위에 지난주 기록 수, 주제 키워드, 확정한 결정, 회의를 보여 줍니다. 화살표로 다른 주를 볼 수 있습니다. 교수자 보기에도 같은 카드가 있지만 "교수자까지" 기록과 공유된 회의만 내용이 보입니다.

## 팀장이 할 수 있는 일

⚙️ 메뉴 → **👥 방 관리**

- 팀원 내보내기, 교수자 접근 끊기 (그 사람의 기록은 방에 남습니다)
- 초대 링크 다시 발급 (예전 링크는 바로 막힙니다). 링크는 7일 동안 쓸 수 있고, 이미 들어온 사람은 만료돼도 그대로입니다
- 팀장 넘기기 (팀장은 넘긴 뒤에야 방에서 나갈 수 있습니다)
- 막힌 접근 기록 보기
- 방 삭제 (되돌릴 수 없습니다. 방 이름을 입력해야 지워지며, 먼저 전체 백업을 받아 두세요)

## 방에서 나가기

⚙️ 메뉴 → **🚪 이 방에서 나가기**. 내 기록과 회의에서 한 말을 함께 지울지 고를 수 있습니다. 지우지 않으면 기록은 방에 남고, 초대 링크로 다시 들어와 이어 쓸 수 있습니다.

## 교수자

교수자용 초대 링크로 들어오면 교수자 보기로만 열립니다. 팀별 기록 수, 결정 수, 참여 편중과 AI 활용 목적을 볼 수 있고, 내용은 "교수자까지" 기록과 공유된 회의 요약만 볼 수 있습니다.

## 확장 프로그램

팀장에게 받은 zip의 `설치 방법.txt`를 따르세요. 대화와 검색 기록은 서버를 거치지 않고 열려 있는 BrainRoom 탭으로만 전달되며, 고른 것만 저장됩니다. PC 브라우저에서만 쓸 수 있습니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "이미 다른 계정이 쓰는 이름" | 다른 계정으로 그 이름을 이미 골랐습니다. 팀장이 방 관리에서 내보내면 다시 고를 수 있습니다 |
| 초대 링크가 안 됨 | 7일이 지났거나 재발급됐을 수 있습니다. 팀장에게 새 링크를 받으세요 |
| 회의 연결이 안 됨 | 학교·회사망은 직접 연결을 막을 수 있습니다. 휴대폰 테더링으로 확인해 보세요 |
| 받아쓰기가 안 됨 | Chrome이나 Edge에서 마이크 권한을 확인하세요 |
| 연동에 "재연결 필요" | 🔌 연동에서 다시 연결하세요 |
| 저장이 거절됐다는 안내 | 권한이 없거나 관리자가 규칙을 아직 게시하지 않았을 수 있습니다 |
